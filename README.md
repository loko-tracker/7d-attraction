# Сайт 7D Attraction

Одностраничный сайт аттракциона. Собран из тех же данных, что и печатный
каталог (`Desktop\7d-catalog`). Никакой сборки и никаких зависимостей:
это обычные HTML, CSS и JS — открываются двойным кликом по `index.html`.

## Что где лежит

```
index.html        разметка страницы
css/style.css     все стили
js/data.js        ВСЁ НАПОЛНЕНИЕ: программы, цены, отзывы, контакты
js/app.js         сборка страницы из данных, фильтры, поиск
img/              53 кадра программ + фон первого экрана
favicon.svg       иконка вкладки
```

## Как менять наполнение

Всё правится в одном файле — `js/data.js`. Пересобирать ничего не нужно,
достаточно обновить страницу в браузере.

**Контакты, часы, адрес** — блок `INFO` в самом верху.

**Цены** — массив `PRICES`. Строка с `hl:true` подсвечивается оранжевым.

```js
{ n:"Один сеанс", s:"Любая программа каталога, 2–6 мин", p:"250 ₽" }
```

**Отзывы** — массив `REVIEWS`. Показываются первые шесть.

**Блок «День рождения»** — объект `BDAY`: заголовок, текст, три цифры и
подпись под кнопкой. `img` — имя кадра из `img/` для фона справа.

**Программы** — массив `FILMS`. Счётчики на первом экране и в каталоге
пересчитываются сами.

```js
{ t:"Название", genre:"Жанр", dur:"5:52", age:"6+", img:"film-01", hit:true, int:4 }
```

| Поле | Что значит |
|---|---|
| `t` | название |
| `genre` | жанр, из него сами собираются кнопки фильтра |
| `dur` | хронометраж `М:СС`, или `"—"` если неизвестен |
| `age` | `0+`, `6+`, `12+`, `16+`, `18+` — цвет плашки подбирается сам |
| `img` | имя файла в `img/` без расширения |
| `hit` | `true` — жёлтая плашка «ХИТ» |
| `int` | интенсивность 1…5, рисуется полосками (только у хитов) |

### Добавить новую программу

1. Положите кадр 16:9 в `img/`, назовите `film-44.webp`.
2. Допишите строку в конец массива `FILMS`.

Пережать картинку под веб (нужен ImageMagick):

```bash
magick исходник.jpg -resize "800x450^" -gravity center -extent 800x450 -quality 80 -strip img/film-44.webp
```

## Как посмотреть локально

Достаточно открыть `index.html` двойным кликом. Если хочется по-честному,
через сервер:

```bash
python -m http.server 5173
```

Затем открыть `http://localhost:5173`.

## Как выложить в интернет

Сайт статический, поэтому подойдёт любой хостинг: достаточно залить папку
целиком. Ничего настраивать на сервере не нужно.

После покупки домена нужно поправить в `index.html` строку
`<link rel="canonical" href="https://7d-attraction.ru/">` — подставить
настоящий адрес.

## Что стоит проверить перед публикацией

- **Возрастная маркировка** проставлена при вёрстке каталога и вами не
  подтверждалась. На сайте она видна каждому — стоит просмотреть список.
- **Хронометраж** у трёх программ неизвестен (`"—"`): Skeleton Island,
  Мишка Гумибеар, Экстремальный кросс. Пока он просто не выводится.
- **Семь программ используют чужие бренды** (Stranger Things, IT,
  Minecraft VR, MainCraft, Мишка Гумибеар, Kingdaka, Dream of Dali).
  Вы решили оставить их на сайте — решение осознанное, но правовой риск
  никуда не делся.
